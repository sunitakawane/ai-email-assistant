# AI EMAIL ASSISTANT

Prototype for implementing AI agent as an email assistant. Developed following the [substack tutorial](https://niharikabatra.substack.com/s/16-week-aiml-series) by Niharika Batra

[Github Link](https://github.com/niharika2309/email-assistant)

Steps
1. Understand Email
2. Plan response
3. Create Draft
4. Review Draft
5. If approved then STOP otherwise Revise and goto step 4
